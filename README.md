# typesafe-meai

Unofficial, experimental proof of concept for decision-oriented model calls in .NET,
validating the proposed `IDecisionClient` abstraction from
[dotnet/extensions#7764](https://github.com/dotnet/extensions/issues/7764).

This is a personal sample/validation repository. It is not a Microsoft product,
is not supported, and its APIs may change or disappear at any time.
